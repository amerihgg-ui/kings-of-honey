# ملوك العسل Enterprise V6

نسخة تشغيلية كاملة بواجهة تطبيقات مستقلة، وتخزين محلي مشترك بين تبويبات المتصفح.

## التشغيل
1. ارفع جميع الملفات والمجلدات كما هي.
2. افتح `index.html` من خادم ويب أو GitHub Pages.
3. بعد استبدال نسخة قديمة اضغط `Ctrl + F5`، أو امسح بيانات الموقع إذا استمر كاش PWA القديم.

## بيانات الدخول الافتراضية
- كلمات مرور المستخدمين الأربعة: `1234`
- كلمة مرور قسم المحاسبة: `1234`

## أهم المزايا
- صفحة تطبيقات نظيفة، المفضلة، وآخر الأقسام استخدامًا.
- كل قسم يفتح في تبويب مستقل وتظل صفحة التطبيقات مفتوحة.
- بحث شامل بـ `Ctrl + K` في الأقسام والعملاء والمنتجات والفواتير والطلبات.
- زر إجراءات سريع.
- نقطة بيع، طلبات، مخزون، مشتريات، فواتير، مصروفات، تقارير ومحاسبة.
- منع مضاعفة المبيعات: الإيرادات من فواتير البيع المعتمدة فقط مرة واحدة.
- فواتير الموردين غير المسددة التزام سالب حتى السداد.
- الفواتير المطبوعة تحمل شعار ملوك العسل وعلامة مائية.
- رفع أو تغيير الصورة الشخصية من الإعدادات.
- مزامنة فورية بين تبويبات نفس المتصفح.
- نسخة يومية محلية ونسخ احتياطي يدوي.

## تنبيه مهم
النسخة الحالية تحفظ البيانات محليًا في المتصفح. الاستخدام المتزامن من أجهزة مختلفة يحتاج قاعدة بيانات وخادمًا مشتركًا (مثل Supabase أو Firebase أو API خاص).
