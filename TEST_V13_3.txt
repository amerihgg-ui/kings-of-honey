اختبار NUVEXA HUB V13.3

1) حفظ طلب جديد
- سجّل بحساب Google.
- أضف منتجًا واضغط تأكيد الطلب.
المتوقع:
✓ لا تظهر infinite recursion.
✓ يظهر رقم ORD.
✓ يظهر الطلب في «الطلبات والتوصيلات».
✓ يظهر في «حسابي» بحالة جديد.
✓ لا تتغير الأرباح ولا المخزون في هذه المرحلة.

2) جاهز للتوصيل / في الطريق
المتوقع:
✓ الحالة تتغير.
✓ لا يُخصم المخزون.
✓ لا يدخل الطلب ضمن إيرادات/أرباح البيع.

3) تم التسليم
قبل التسليم دوّن:
- مخزون المنتج.
- سعر البيع.
- تكلفة المنتج.
بعد الضغط «تم التسليم»:
✓ المخزون ينخفض بكمية الطلب (للمنتج المادي فقط).
✓ تظهر فاتورة بيع.
✓ الإيراد يزيد بسعر البيع.
✓ COGS تزيد = تكلفة المنتج × الكمية.
✓ الربح يزيد = الإيراد - COGS.
✓ الحسابات والتقارير تعرض القيم الجديدة بعد فتح القسم.

مثال:
سعر البيع 1000، التكلفة 600، الكمية 1
=> الإيراد +1000
=> تكلفة البضاعة +600
=> الربح +400 قبل المصروفات.

4) مصروف
سجّل مصروفًا 100.
المتوقع:
✓ المصروفات +100.
✓ الربح التشغيلي ينخفض من 400 إلى 300.

5) مرتجع بعد التسليم
المتوقع:
✓ المخزون يرجع.
✓ البيع المرتجع لا يبقى محسوبًا في الربح.
✓ الفاتورة تظهر كمستردة/غير معترف بها كإيراد نشط.

6) واتساب
المتوقع:
✓ الطلب يُحفظ داخل المنصة أولًا.
✓ بعدها يفتح واتساب.
✓ رسالة واتساب تحمل رقم ORD الحقيقي.
