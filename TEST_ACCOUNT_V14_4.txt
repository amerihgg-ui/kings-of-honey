اختبار «حسابي» V14.4

1) بدون تسجيل:
- اضغط حسابي.
المتوقع:
✓ Split Screen واسع.
✓ شعار NUVEXA كبير في الجزء البصري.
✓ Google Login يعمل.
✓ الدخول بالاسم والهاتف يعمل.

2) بعد تسجيل الدخول:
- اضغط حسابي.
المتوقع:
✓ الحساب يملأ أغلب مساحة الشاشة.
✓ بيانات العميل في الجانب.
✓ الاسم والصورة والإيميل/الهاتف ظاهرون.
✓ زر تسجيل الخروج يعمل.

3) الطلبات:
✓ كل طلب يظهر برقم وحالة ومبلغ.
✓ خط الحالة يعكس جديد/جاهز/في الطريق/تم التسليم.
✓ بيانات الطلب لا تتغير بسبب التصميم.

4) المشتريات الرقمية:
✓ الترخيص يظهر دون تغيير وظيفته.

5) التنقل:
✓ أزرار نظرة عامة/طلباتي/المشتريات الرقمية تنقل داخل الحساب.

6) الأداء:
✓ فتح وإغلاق حسابي عدة مرات لا يزيد البطء.
✓ لا تتكرر عناصر التصميم.
