اختبار V13.4 — حالة الطلب بضغطة واحدة

1) افتح «الطلبات والتوصيلات».
2) اضغط على شارة «جديد» الموجودة في خانة الحالة.
المتوقع:
✓ تفتح قائمة الحالات مباشرة.

3) اختر «جاهز للتوصيل».
المتوقع:
✓ تتغير الحالة فورًا.
✓ يراها العميل في «حسابي».
✓ لا يتم خصم المخزون أو احتساب الربح.

4) اضغط الحالة واختر «في الطريق».
المتوقع:
✓ تتحدث الحالة فقط.

5) اضغط الحالة واختر «تم التسليم».
المتوقع:
✓ يظهر تأكيد قبل التنفيذ.
✓ بعد التأكيد: يتم خصم المخزون.
✓ تظهر/تعتمد فاتورة البيع.
✓ يتم تحديث الإيراد والتكلفة والربح والتقارير.

6) اضغط «تم التسليم».
المتوقع:
✓ القائمة تعرض «مرتجع».
✓ اختيار مرتجع يعرض تأكيدًا.
✓ بعده يرجع المخزون وتنعكس الأرقام المالية.

7) الطلب الملغي:
✓ يمكن إعادة فتحه كـ «جديد» بعد تأكيد.
